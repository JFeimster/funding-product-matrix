# Funding Agency Automation Pack

A practical broker operations pack by **Moonshine Capital** for funding brokers, ISOs, referral partners, processors, VAs, consultants, and agency owners who want cleaner lead intake, follow-up, document collection, CRM hygiene, and AI-assisted workflow automation.

This is not a generic AI tool dump. It is a field kit for building a tighter funding agency operating system without letting the robot make promises it has no business making.

## How to Use This Pack

Use the files in order if you are building from scratch. Use them à la carte if you already have a CRM, intake form, document process, or referral partner motion.

Best workflow:

1. Score your current operation with the automation checklist.
2. Clean up CRM stages before adding automations.
3. Standardize borrower intake.
4. Standardize missing-document follow-up.
5. Generate internal deal summaries with human review.
6. Apply AI safety rules before borrower-facing automation.
7. Decide what to automate, assist, or keep human.
8. Map the workflow in n8n, Zapier, Make, or your CRM.
9. Build a referral partner follow-up loop.

## Core Doctrine

> Automate the admin. Assist the analysis. Human-review the money talk. Audit everything.

This doctrine should govern every prompt, script, CRM stage, automation, and partner workflow in this folder.

Start with:

- `broker-ai-automation-checklist.md`
- `automate-vs-keep-human-decision-matrix.md`

Use these to figure out what is ready for automation, what needs documentation first, and what must stay human.

### 2. Clean the Pipeline

Move next to:

- `crm-stage-map-for-funding-brokers.md`
- `borrower-intake-prompt.md`
- `missing-document-follow-up-script.md`

This is where the pipeline stops being a haunted spreadsheet and starts acting like an operating system.

### 3. Build the Review Layer

Use:

- `deal-summary-prompt.md`

This helps turn borrower data, CRM notes, documents, and funding requests into an internal review summary. It is not an approval engine. It is a clarity engine.

### 4. Wire the Automations

Use:

- `n8n-zapier-workflow-map.md`

This maps the practical workflow from lead form to CRM record, AI intake summary, broker notification, document checklist, follow-up reminders, file completion, deal summary, status update, and renewal/nurture sequence.

### 5. Build the Partner Loop

Use:

- `referral-partner-follow-up-templates.md`

This helps brokers manage accountants, bookkeepers, coaches, consultants, real estate pros, ecommerce advisors, local connectors, and existing clients as referral partners.

## Broker Safety Note

This pack is for operational support, workflow design, and AI-assisted drafting. It is not lender, legal, tax, accounting, compliance, or underwriting advice.

Do not use these files to:

- Guarantee funding approval
- Promise borrower qualification
- Promise broker income
- Quote final terms without lender review
- Claim Moonshine Capital is a bank
- Replace broker judgment
- Replace legal, tax, accounting, compliance, lending, or underwriting review
- Send deceptive outreach
- Scrape private or restricted data
- Automate sensitive borrower communication without human review

Use careful language:

- may help
- can support
- eligibility varies
- terms may change
- lender review required
- human review required
- not a guarantee
- consult qualified professionals where appropriate

## Automation Boundary Rules

| Workflow Type | Recommended Treatment |
| --- | --- |
| Lead notification | Safe to automate |
| CRM tagging | Safe to automate with periodic audit |
| Missing document reminders | Safe to automate with approved templates |
| Intake summaries | AI-assisted, broker reviewed |
| Deal summaries | AI-assisted, broker reviewed |
| Bank statement summaries | AI-assisted, human reviewed |
| Lender-fit notes | AI-assisted, broker/lender reviewed |
| Offer explanations | Human-led with approved language |
| Decline explanations | Human-led with careful language |
| Final funding decisions | Human/lender only |
| Legal/tax/accounting guidance | Qualified professionals only |
| Earnings claims for broker programs | Human-approved only; no unsupported claims |

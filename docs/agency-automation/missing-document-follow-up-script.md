# Missing Document Follow-Up Script

A practical follow-up script pack for funding brokers, processors, broker VAs, ISOs, referral partners, and funding agency teams who need borrowers to send missing documents without sounding desperate, pushy, confusing, or legally reckless.

This file helps you follow up on missing documents with clear borrower-facing messages, CRM notes, and automation trigger ideas.

## How to Use This File

Use these scripts when a borrower has started the funding process but has not completed the required document checklist.

Recommended workflow:

1. Confirm exactly which documents are missing.
2. Update the borrower profile and CRM stage.
3. Send the correct SMS or email script.
4. Log the follow-up in the CRM.
5. Set the next follow-up date.
6. Move the borrower to nurture if they do not respond after the final reminder.

Do not use these scripts to pressure a borrower, promise approval, quote terms, or imply that funding is guaranteed after documents are submitted.

## Broker Automation Doctrine

Use this rule across every document collection workflow:

> Automate the admin.  
> Assist the analysis.  
> Human-review the money talk.  
> Audit everything.

Document reminders can be automated. Funding conversations, lender-fit decisions, offer explanations, and sensitive borrower concerns should receive human review.

## Tone Rules

Every missing document follow-up should be:

- Clear
- Specific
- Calm
- Helpful
- Short enough to act on
- Free of fake urgency
- Free of approval promises
- Free of shame
- Easy to copy, reply to, or forward

Avoid sounding like a collections department wearing a fintech hoodie. The goal is movement, not panic.

## Standard Follow-Up Cadence

This cadence is a practical starting point. Adjust based on borrower consent, communication preferences, CRM rules, and applicable messaging requirements.

| Touch | Timing | Channel | Goal |
|---|---|---|---|
| Reminder 1 | Same day or next business day | SMS + email | Clarify what is missing |
| Reminder 2 | 2 business days later | SMS or email | Keep the file moving |
| Final reminder | 3-5 business days later | Email + optional SMS | Move to nurture if no response |
| Nurture | 7-14 days later | Email | Keep door open without chasing ghosts |

## Suggested CRM Stages for Document Follow-Up

Use these stages to keep the file from becoming a haunted filing cabinet.

| Stage | Meaning | Next Action |
|---|---|---|
| Docs Requested | Borrower has received document checklist | Wait for upload or send first reminder |
| Docs Partially Received | Some items received, some missing | Send specific missing document reminder |
| Bank Link Pending | Borrower has not completed bank connection | Send bank link reminder |
| File Complete | Required documents received | Broker reviews before submission |
| Not Ready | Borrower lacks required documentation or timing is off | Nurture and set future follow-up |
| Lost / Nurture | Borrower stopped responding | Enter long-term follow-up sequence |
| Do Not Pursue | File should not continue | Stop automation and document reason |

## What Not to Say

Avoid these phrases. They create compliance risk, borrower confusion, or both.

| Do Not Say | Why It Is Risky | Safer Alternative |
|---|---|---|
| Send these and you are approved. | Implies guaranteed approval. | These documents help complete the file for review. |
| Once we get statements, we can get you funded. | Suggests funding is certain. | Once received, we can continue reviewing possible options. |
| No documents needed. | Usually inaccurate and misleading. | Documentation requirements vary by product and lender. |
| Everyone qualifies. | False and risky. | Eligibility varies based on the business profile and lender review. |
| This is your last chance. | Fake urgency. | If now is not the right time, we can pause and reconnect later. |
| The lender will definitely approve this. | Makes an unsupported underwriting claim. | Final decisions are subject to lender review. |
| Your credit does not matter at all. | Overbroad and product-dependent. | Some options may weigh revenue and bank activity more heavily than credit, but eligibility varies. |
| I guarantee better terms. | Unsupported guarantee. | We can review available options if the file is complete. |

## Borrower Reply Handling Rules

Use these rules to decide when automation should continue and when a human should step in.

| Borrower Reply | Suggested Handling |
|---|---|
| “I uploaded it.” | Confirm receipt, update CRM, verify file status. |
| “I do not know what this means.” | Send simplified one-document request. |
| “Am I approved?” | Human broker response required. |
| “What rate can I get?” | Human broker response required. Do not quote terms without review. |
| “I cannot access the bank link.” | Send troubleshooting steps or assign processor. |
| “I already sent this.” | Check CRM/uploads before replying. Do not argue. |
| “Stop texting me.” | Stop SMS follow-up and update communication preference. |
| “I changed my mind.” | Move to Lost / Nurture or Closed based on policy. |

## Human Review Checklist Before Submission

Before any file moves from File Complete to Submitted to Lender, confirm:

- [ ] Borrower profile is complete.
- [ ] Funding request is clear.
- [ ] Use of funds is documented.
- [ ] Time in business is documented.
- [ ] Monthly revenue is documented.
- [ ] Bank statements or bank link have been reviewed as required.
- [ ] Missing document field is empty or intentionally waived by process.
- [ ] Existing debt/advance notes are updated.
- [ ] Referral partner is tagged, if applicable.
- [ ] No approval promises were made in borrower communication.
- [ ] Broker reviewed lender-fit considerations.
- [ ] Sensitive borrower data is stored only in approved systems.

## Broker Safety Note

Document collection involves sensitive borrower data. Use approved storage systems, secure upload links, permission-based communication, and human review before lender submission. Do not request documents you do not need. Do not store sensitive borrower data in random notes, personal inboxes, screenshots, unsecured spreadsheets, or AI tools that are not approved for that data type.

These templates do not provide legal, tax, accounting, lending, or underwriting advice. Submitting documents does not guarantee approval, specific terms, funding speed, or lender acceptance. Eligibility varies, terms may change, documentation may be required, and lender review is required.
